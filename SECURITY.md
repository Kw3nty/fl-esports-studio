# Безопасность

## Как сообщить об уязвимости

Пожалуйста, не публикуйте уязвимости в открытых issue. Отправьте приватный отчёт: вкладка **Security** → **Report a vulnerability** в этом репозитории. Опишите, что нужно сделать для воспроизведения, и на какой версии это проверено. Ответ обычно приходит в течение нескольких дней.

## Что входит в область

- `FL Esports Studio.exe`: локальный сервер интерфейса на `127.0.0.1:38475`, прокси к службе, автозапуск и значок у часов;
- интерфейс (HTML и JS): команды к клавиатуре, чтение файлов резервных копий `.json`;
- скрипты сборки и GitHub Actions.

## Что не входит

- `iot_driver.exe` и оригинальный «F. L Driver»: это программы производителя, о проблемах в них сообщайте ему;
- предупреждения SmartScreen из-за того, что exe не подписан.

## Принципы

- Программа не обращается в интернет и слушает только `127.0.0.1`.
- Команды обновления прошивки и загрузчика не реализованы намеренно. Pull request'ы с ними не принимаются.
- Релизы собираются в GitHub Actions из исходников этого репозитория, SHA-256 публикуется рядом с архивом.

---

**English:** please report vulnerabilities privately via **Security** → **Report a vulnerability**. Do not open public issues for security problems.
